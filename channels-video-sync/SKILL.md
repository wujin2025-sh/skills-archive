# 微信视频号极速全自动同步技能 (Channels Video Sync v3.0 Ultra)

专门用于将剪辑压制完成的 1080P 视频母带及定制典藏封面，极速、全自动同步存入**微信视频号助手草稿箱**（`https://channels.weixin.qq.com/platform/post/create`）。


### 2. 参数选项
| 参数 | 缩写 | 说明 |
| :--- | :--- | :--- |
| `--video` | `-v` | **必需**。视频母带本地绝对路径（.mp4/.mov） |
| `--cover` | `-c` | 可选。定制封面海报路径（9:16 或 3:4 竖版图片） |
| `--title` | `-t` | 短标题（系统严格限制最大 16 字符，优先体现文章涉及的核心券商） |
| `--long-title` | `-lt` | 可选。完整长标题（用于置顶于视频描述第一行） |
| `--desc` | `-d` | 视频正文描述及话题标签 |
| `--collection` | `-col`| 视频号合集名称（默认：`大国券商`） |
| `--no-original`| | 可选。不进行原创作品声明（默认强制自动声明原创） |

## 🔒 避坑与运行准则 (铁律)
1. **默认强制【声明原创】**：所有同步任务默认必须勾选并确认声明原创。引擎自动穿透并处理“原创权益”弹窗协议，自动勾选同意并点击弹窗内的【声明原创】确认按钮，严禁漏勾或跳过；
2. **描述格式排版铁律 (Long Title First)**：视频描述必须严格按照“**【长标题】 ➔ 空行换行 ➔ 正文精彩故事矛盾与细节 ➔ 空行换行 ➔ 垂直话题标签**”格式输出，禁止无长标题或正文与长标题挤在同一行；
3. **点击【保存草稿】即全链路圆满退出**：用户明确界定同步流程终点：一旦成功触发【保存草稿】按钮（物理硬件点击 + JS 双重派发），同步流程即刻结束并优雅退出，无需继续在页面等待或轮询草稿列表；
4. **短标题 16 字符硬上限**：视频号发表助手短标题输入框存在 16 字符硬上限，超出将阻断草稿保存，引擎内置严格自动截断保护，且标题优先体现本篇核心券商；
5. **微前端 Shadow DOM**：视频号发表组件嵌入在 `<wujie-app>` 微前端 Shadow 树中，常规 DOM 选择器无法直接抓取，必须使用 `wujie.shadowRoot` 穿透访问；
6. **真实用户交互**：上传按钮被浏览器同源策略保护，引擎通过 macOS CoreGraphics 发送硬件级事件，规避合成事件被浏览器静默拦截的问题。
