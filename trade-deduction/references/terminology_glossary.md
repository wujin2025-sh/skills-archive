# 交易清算与两融规范术语词典 (Terminology Glossary)

本词典收录国泰海通核心交易与清算系统中交易推演相关的标准专业术语，遵循 `LRN-20260728-006`“忠于事实、禁用捏造”原则。

---

## 一、 资产与持仓类

| 规范术语 | 英文 / 别称 (仅参考) | 作用域 | 算式 / 精确定义 | 常见误用 / 禁用词 |
| :--- | :--- | :--- | :--- | :--- |
| **刨除融资买入数量** | Net Non-Margin Quantity | 证券级 (股/份) | $\max(\text{总持仓数量} - \text{融资买入数量}, 0)$ | 禁用 `剩余数量`、`普通数量` |
| **高流通持仓市值 (刨除融资买入)** | Net High-Liquidity Value | 证券级 / 账户级 (元) | $\sum \text{刨除融资买入数量} \times \text{价格}$。风控与占用抵扣的核心基准。 | 禁用 `总持仓市值` 替代 |
| **高流通证券白名单** | Whitelist Securities | 领域级 | 允许使用融券卖出资金买入的货币基金、债券 ETF 及高流动性股票集合。 | - |

## 二、 资金与占用类

| 规范术语 | 英文 / 别称 (仅参考) | 作用域 | 算式 / 精确定义 | 常见误用 / 禁用词 |
| :--- | :--- | :--- | :--- | :--- |
| **融冻占用** | Margin Freeze Occupation | 账户级 (元) | 买入货基/白名单证券所占用的融券受限资金。属于受限解冻池。 | 禁用 `冻结金额`、`freeze_amt` |
| **融冻款金额** | Released Margin Cash | 账户级 (元) | 已从占用中释放、可自由使用的融冻可用现金池。 | 禁用 `解冻资金` |
| **预冻结代扣税** | Pre-frozen Tax | 账户级 (元) | 扣税日当天系统优先预扣的行权/分红红利税资金。 | 禁用 `预扣税款` |
| **资金余额** | Cash Balance | 账户级 (元) | 账户当前总现金余额。 | 禁用 `balance` |
| **自有可用现金** | Free Available Cash | 账户级 (元) | 不含融冻款与受限资金的自由可用现金。 | 禁用 `可用` (笼统) |

---

## 三、 负债与风控类

| 规范术语 | 英文 / 别称 (仅参考) | 作用域 | 算式 / 精确定义 | 常见误用 / 禁用词 |
| :--- | :--- | :--- | :--- | :--- |
| **融资负债** | Margin Buying Debt | 账户级 (元) | 客户融资买入产生的本金与利息负债总额。 | 禁用 `margin_debt` |
| **维持担保比例 (维保比)** | Maintenance Margin Ratio | 账户级 (%) | $\frac{\text{总资产} - \text{融冻占用}}{\text{总负债}} \times 100\%$ | 禁用 `维保率` |
| **追保线 / 平仓线** | Margin Call / Liquidation Threshold | 账户级 (%) | 追保线标准为 $130\%$，平仓线标准为 $110\%$。 | - |
| **负数倒挂 (倒挂溢出)** | Negative Balance Overflow | 异常现象 | 持仓市值小于融冻占用且未联动释放导致的资金与风控负数溢出故障。 | - |

## 四、 清算与划拨规则

| 规范术语 | 定义与适用场景 |
| :--- | :--- |
| **三段式划拨** | 卖出/还款变现资金的法定划拨顺序：**1. 优先释放融冻占用回转融冻款 $\rightarrow$ 2. 清偿融资/融券负债 $\rightarrow$ 3. 划入自有可用现金**。 |
| **代扣税最高优先级** | 扣税日当天，预冻结代扣税在资金扣减顺序上高于融资行权债务抵偿。 |
| **强平特例不拦截** | 账户触发强制平仓线 (110%) 时，豁免常规卖出拦截，所得资金全额充实受限资金池。 |
| **T+1 清算批处理** | 区分盘中实时更新与 T+1 批处理清算时点的指标变动。 |
