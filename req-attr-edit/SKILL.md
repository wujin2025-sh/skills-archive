# 需求属性修改

## 概述

访问国泰海通金融科技平台「需求管理」详情页，通过展开“需求要素”面板定位具体的属性要素（例如“重点关注”、“需求自定义标签”、“是否大小远期同步测试”等），自动触发修改并保存，支持 Session 免登录态复用。

本技能支持以下模式：
1. **单笔修改模式**：指定单个需求编号（形如 `R2606160037`），进行精准定位与修改。
2. **史诗批量修改模式**：指定史诗编号（形如 `E2603040001` 或 `PG202204-0267`），系统自动通过史诗管理 API 获取该史诗下的所有关联需求（如 E2603040001 的 9 个需求），并在同一个浏览器会话中顺序完成批量修改。
3. **标签/同步测试修改**：自动支持 `标签`、`同步测试`、`是否大小远期同步测试` 等别名。其中 `标签` 映射至 `需求自定义标签`（修改详情页标签）；`同步测试` / `是否大小远期同步测试` 映射至 `isSynTest`（修改大宽表/网格中该需求下所有 Story 的是否大小远期同步测试属性，目标值为是/否）。

## 触发条件

当用户提及以下关键词或意图时使用本技能：

- **修改需求属性**、**修改属性要素**
- **修改重点关注字段**、**重点关注修改**、**修改为重点关注**
- **按史诗编号修改属性**、**根据史诗编号修改重点关注**
- **标签属性修改**、**需求自定义标签修改**、**同步测试修改**、**是否大小远期同步测试**
- 提供需求编号或史诗编号并要求修改某属性，如：
  - `修改 R2606160037 重点关注为是`
  - `新增 标签 属性修改功能 R2607090122 标签 CX-信用-两融`
  - `新增 是否大小远期同步测试 属性修改功能 R2607130042 同步测试 是`

## 使用方法

脚本位于 `scripts/edit_attr.py`，在工作虚拟环境中运行：

```bash
.venv/bin/python /Users/wujin/.workbuddy/skills/req-attr-edit/scripts/edit_attr.py <需求编号/史诗编号> <字段名/别名> <目标值> [--headed]
```

### 示例：
- 将史诗 `PG202204-0267` 下的所有关联需求修改「重点关注」为「是」：
```bash
.venv/bin/python /Users/wujin/.workbuddy/skills/req-attr-edit/scripts/edit_attr.py PG202204-0267 重点关注 是
```

- 将需求 `R2606160037` 的 `重点关注` 字段修改为 `是`：
```bash
.venv/bin/python /Users/wujin/.workbuddy/skills/req-attr-edit/scripts/edit_attr.py R2606160037 重点关注 是
```

## 技术细节

- **API 级联检索**：对于史诗编号输入，先从已存 Session 提取 Token 及 Cookies，通过 `getSheetContent` 大宽表接口过滤出该史诗下关联的所有需求 ID，支持 Layer 1 内存极速匹配。
- **单会话批量执行**：Playwright 启动后一次性遍历所有待修改需求 ID 进行页面导航与修改，复用浏览器实例，最大限度提升批量修改的效率。
- **元素动态定位**：使用 CSS 兄弟选择器 `th:has-text('{field_name}') + td` 精确匹配属性名与其值容器。
- **自动值过滤**：比对当前值与目标值，若已经是目标值，会安全地自动跳过，避免网络提交与防刷报警。
