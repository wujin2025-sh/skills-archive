# 微信公众号【贴图】自动化创作与草稿箱同步技能 (WeChat Sticker Sync Skill)

本技能专门用于将微信公众号的**深度长图文**快速降维、提炼为符合平台公域推荐偏好的**高颜值“贴图 / 图片消息”（小绿书模式，`type=77&createType=8`）**，并支持自动渲染 3:4 封面大图与**全自动免扫码存入公众号后台草稿箱**。

---

│   • 精选 5 张真实历史实物 / 纪实档案原图                   │
└───────────────────────────┬────────────────────────────┘

                            ▼
┌────────────────────────────────────────────────────────┐

## 📐 贴图黄金规范（严格参照【大国股事 01/02】标准）

### 1. 标题规范
* **字符上限**：微信公众平台贴图标题限制在 **20 字符以内**（超限无法输入或报错）。
* **格式模板**：`【大国股事 XX】核心事件/主旨短语`（如 `【大国股事 02】深南大道的雨夜长队`，正好 18 字）。

### 2. 正文叙事节奏（约 600~750 字）
* **第 1 行（独立成段）**：一句提纲挈领的全局总结金句（如：*大国资本市场的规则与法度，是老百姓顶风冒雨硬生生撞出来的。*）
* **第 2~5 段（四幕微故事）**：
  * 采用纯粹的 `四字/六字小标题：紧凑情节叙事` 格式；
  * 每段字数控制在 100 ~ 140 字，信息密度极高，杜绝官话空话；
* **末尾段（独立成段）**：一句点睛升华金句（如：*这几卡车踩烂的塑料拖鞋撞出的，是一个国家资本市场的百年法度。*）

### 3. 6 图闭环卡片流
* **图 1**：大字封面海报（1080×1440，暖底大字 + 双引号 + 核心词橙色高亮）；
* **图 2**：核心实物扫描件（如抽签表、股票票样、批文）；
* **图 3**：震撼纪实全景/长焦（如前胸贴后背的人肉长队、马路柜台）；
* **图 4**：风暴与对峙现场（如营业部门前汹涌人潮、红布对峙）；
* **图 5**：转折与救火凭证（如紧急兑换券、停牌通告）；
* **图 6**：监管里程碑/核心领军人物（如证监会成立、刘鸿儒履新肖像）。

## 🛠️ CLI 自动化工具使用说明

脚本统一存放于本 Skill 的 `scripts/wechat_sticker_tool.py`。

### 1. 一键生成 3:4 封面海报 (make-cover)
```bash
python3 ~/.workbuddy/skills/wechat-sticker-sync/scripts/wechat_sticker_tool.py make-cover \
  --html "【大国股事<br>02】 <span class=\"highlight\">深南大道</span><br>的雨夜长队，<br>撞出了中国<br>证监会" \
  --output "images/02_cover_gushi.png"
```

### 2. 一键同步贴图 MD 到微信公众平台草稿箱 (sync)
```bash
# 静默无头模式（已登录状态下推荐，自动上传并保存草稿）
python3 ~/.workbuddy/skills/wechat-sticker-sync/scripts/wechat_sticker_tool.py sync \
  -f "证券风云系列/【大国股事 02 贴图】深南大道的雨夜长队与中国证监会紧急诞生.md"

# 有头调试模式（若 Session 过期，自动弹出窗口供微信扫码）
python3 ~/.workbuddy/skills/wechat-sticker-sync/scripts/wechat_sticker_tool.py sync \
  -f "证券风云系列/【大国股事 02 贴图】深南大道的雨夜长队与中国证监会紧急诞生.md" --headed
```

## 🔒 登录与风控机制
* 首次扫码后，Cookies 与浏览器状态保存在 `~/.wechat_mp_playwright_profile`；
* 只要微信公众平台未强制踢出，后续执行任务**零等待、免扫码、秒级直达**；
* 遇到登录失效，控制台会主动暂停并提示扫码，扫码完成后自动继续，无需手动重启。
