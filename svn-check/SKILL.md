# svn-check (SVN 分支差异并发检查技能)

此技能能够自动化、并发检查特定需求号或任务号在 UAT 仓库与生产（Produce）仓库中的提交版本差异。本工具**仅检查差异，不做任何修改**，支持 Windows 与 macOS 环境，并且会自动根据当前操作系统适配其默认的命令行工具。

支持将 Excel 复制的多行“Task编号-任务”表格数据作为输入，按编号提取后利用多线程并发进行高效比对。

## 工作原理与流程

1. **输入解析**：解析输入的需求/任务数据，提取出所有的唯一编号列表。
2. **HEAD 探测与区间比对**：通过 `svn info` 获取最新 `HEAD` 版本号，并在限定区间内（默认最近 20000 个版本，约 2-3 年）搜索。这样可免去全量扫描数十万版本的缓慢过程。
3. **并发日志检索**：使用 `ThreadPoolExecutor` 对每个编号并发执行 `svn log --search <ID> --xml` 同时检索 UAT 仓库与生产仓库的提交记录，耗时不再随着编号数增加而线性累加。
4. **状态比对**：
   * **两边无记录**：UAT 和生产都没有此编号的提交。根据用户要求，此状态视为无差异、正常并跳过。
   * **仅生产有记录**：UAT 中没有此编号的提交，但生产有（可能被回滚或分支历史差异）。
   * **已同步**：UAT 里的最新提交记录的时间不晚于生产。
   * **UAT较新 (未同步)**：UAT 有提交记录但生产中没有，或者 UAT 最新提交时间晚于生产最新提交时间。
   * **生产已回退**：若生产最新一次提交中包含 `revert`、`rollback`、`回退`、`撤销`、`未验收` 等字样，会自动判定为生产已回退，即 UAT 的修改视为全部待同步。
5. **报告生成**：检查结束后，在控制台输出美化的汇总表格，同时在输出目录下生成：
   * `svn_check_summary_<时间戳>.txt`：整体执行的分类统计与明细。
   * `svn_check_report_<时间戳>.md`：详细的 Markdown 比对报告（包含所有待发布 Revisions 详情）。

## 常用参数与配置

命令行调用支持以下参数：

| 参数 | 缩写 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `--data-text` | `-d` | *无* | 合并输入数据，可以是**换行/空格/逗号分隔的文本**、**文本文件路径**，或通过标准输入 **stdin** 传入。 |
| `--range-size` | `-r` | `20000` | 限制检查的版本范围大小。比对最近的任务可设置更小值（如 `-r 5000`）来获得更极速的比对。 |
| `--workers` | `-w` | `10` | 最大并发查询线程数。对于大批量编号，该参数可大幅缩减总用时。 |
| `--full-history`| `-f` | *False* | 查询完整历史 (不设版本区间限制)。仅在定位极其古老的需求且默认区间找不到时使用，耗时较长。 |
| `--uat-url` | `-s` | `https://jyjs.svn.gtja.net/svn/jjywpt/Src/01Branches/spbsrc_uat_2024` | UAT 来源分支的 SVN 仓库 URL。 |
| `--prod-url` | `-t` | `https://jyjs.svn.gtja.net/svn/jjywpt/Src/01Branches/Produce` | 生产目标分支的 SVN 仓库 URL。 |
| `--svn-username` | `-u` | *空* | SVN 认证用户名。macOS 默认免填，会自动使用系统钥匙串认证。 |
| `--svn-password` | *无* | *空* | SVN 认证密码。macOS 默认免填，支持传入明文或 `ENC:...` 加密密码。 |
| `--svn-executable` | *无* | *空* | 手动指定的 `svn` 命令行工具路径。 |
| `--output-dir` | `-o` | `./svn_check` | 输出报告的路径，默认在当前工作目录的批次前缀文件夹下。 |

## 使用说明

### 代理调用指南

当用户要求您协助检查版本差异时，您需要：
1. **收集输入数据**：提示用户提供要检查的任务号/需求号（可以是一个，也可以是多个，支持直接复制 Excel 表格）。
2. **极速核对推荐**：默认建议用户传入 `-r 5000` 来获得数秒内的极速核对结果。如果出现“两边无记录”，告知用户该任务已被判定为正常无差异跳过。
3. **构造并执行命令**：
   * 执行以下命令示例：

```bash
# 方式 1：多编号并行极速检查（限制在最近 5000 个版本）
python3 /Users/wujin/.workbuddy/skills/svn-check/scripts/svn_check.py \
  -r 5000 \
  -d "JZJYPT-T202504823,JZJYPT-T202505612"

# 方式 2：使用 stdin 传入多行 Excel 复制的数据，并设置 10 个并发线程
cat << 'EOF' | python3 /Users/wujin/.workbuddy/skills/svn-check/scripts/svn_check.py -w 10
JZJYPT-T202504823	123456	债券质押式开发需求	蔡静雯-123576
JZJYPT-T202505612	123457	另一个开发需求	李四-123456
EOF
```

4. **解析并展示结果**：
   * 读取终端输出的汇总表格，并将生成的 `svn_check_report_*.md` 报告内容以 Markdown 格式友好呈现给用户。

## macOS 环境支持 (TLSv1.0 + 钥匙串)

本脚本内置了对 TLSv1.0 协议和 Keychain 免密认证的自动处理：
- 自动生成临时 OpenSSL 配置文件并设置 `OPENSSL_CONF` 环境变量，避免 E120171 SSL 通信错误。
- 默认不传入 `-u` 与 `--password` 参数，使 Subversion 能直接从 macOS 钥匙串自动解锁并认证。
