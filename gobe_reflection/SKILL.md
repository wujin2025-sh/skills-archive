# GOBE 深度复盘与职场系统升维 Engine (v2.0 旗舰版)

本 Skill 结合 **GOBE 5大底层心智** 与 **专业复盘 (GRA - Goal, Result, Analysis, Action) 方法论**。

**核心宗旨**：打破机械流水账总结与单点调试，站在全局视角，通过“目标-结果对比、5-Why 根因剖析、心智解绑与双环学习”，提供具备显式修改优先级（P0/P1/P2）的专业改善建议，并**自动回流闭环至任务清单与系统规则**中。

> [!IMPORTANT]
> **Skill 优化的终极目标：质量越好，速度越快！**
> 每次评估、设计与优化 Skill 时，必须同时从“质量防线”与“速度效率”两个维度双向衡量：
> 1. **质量越好 (Quality Excellence)**：
>    - **零捏造与防误杀**：严守数据真实性（如数据库物理表名防捏造、推演算式显式代入）；
>    - **自动校验与双向比对**：引入跨系统 MD5 哈希校验、自动标点中英文纠错与异常高亮；
>    - **高质感资产交付**：默认产出格式严谨的 Markdown、网页级 HTML 卡片与可视化架构图。
> 2. **速度越快 (Speed & Efficiency)**：
>    - **单一源强收拢**：全量技能统一存放于 `~/.workbuddy/skills/`，消除多头版本寻址摩擦；
>    - **极致自动化与防假死**：Session 复用、多线程并行、无头后台静默起草，避免 UI 卡顿与联想吞字；
>    - **干练高聚焦输出**：彻底过滤已完成的冗余历史清单，只呈现在手 Gap 与 Action，大幅提升协作决策速度。

## 🚦 修改优先级分级规范 (Priority Matrix Directives)

所有针对性改进建议、警示雷达与 Action Items 必须显式标注**修改优先级**：

- 🔴 **P0 (高优先级 - 紧急高收益 / 红线防爆)**：严重影响需求准确性、资金算式安全、代码合并冲突、单据填报 UI 假死或数据混淆漏洞。**必须立即优先优化**！
- 🟡 **P1 (中优先级 - 流程增效 / 规范收拢)**：明显提升跨部门协同、简报汇报或周报闭环效率的规范项。建议在近期迭代中落地。
- 🟢 **P2 (低优先级 - 视觉提质 / 长远演进)**：美学细节、长远机制演进或低频边缘场景优化项。按需逐步演进。

## 💡 5 大底层心智模型 (GOBE Framework)

1. **5分钟行动试跑法则 (Action-First Model)**：破除假性拖延，灵感“咯噔”一下立即开启 5 分钟试跑，借助 AI 跳过冗余步骤。
2. **系统2决策防偏与解绑法则 (System 2 Disentanglement)**：严格区分“信息层的被理解”与“判断层的被同意”。踩下 3 秒刹车，区分观点反驳与个人否定。
3. **AI 个人操作系统化法则 (Personal OS Component)**：拒绝工具单次调用模式，把 AI 作为底层环境，自动化处理机械流程与上下文记忆。
4. **问题层级升维法则 (Problem Tier Escalation)**：从“执行者 (完成)”到“问题解决者 (改善)”，再升维至“系统贡献者 (构建机制)”，向上追问三层寻找根因。
5. **结构化资产交付法则 (Structured Asset Delivery)**：完成的标志是共识达成与机制沉淀。输出 1 页可视化架构图、标准 SOP 或自动化 Skill 资产。

## 🔬 5-Why 根因追问标准结构 (RCA Standard)

在剖析踩坑或漏洞时，必须按以下 5 级连环追问，拒绝停留在表面现象：

- **Why 1 (现象表征)**：发生了什么表面异常？
- **Why 2 (直接操作失误)**：触发异常的具体动作是什么？
- **Why 3 (流程/代码缺失)**：为什么现有的代码/流程没有防住该动作？
- **Why 4 (机制/SOP 漏洞)**：为什么机制或测试用例没有覆盖此场景？
- **Why 5 (架构防线缺失 - 根因)**：底层设计哲学或规范红线缺失了什么？
- **👉 双环解法 (Double-Loop Action)**：改写的不仅仅是单点代码，而是覆写 Skill 防线规范或更新知识库 SOP。

## 📂 强制落盘与任务回流闭环规则

> [!IMPORTANT]
> **🧹 彻底过滤已完成事项防线 (Filter Out Completed Items)**：
> 生成复盘报告与同步待办池时，**严格过滤并删除所有已完成的项目（`[x]`）与历史已履约大列表**，仅保留当下真实存在的 Gap、改进建议及未完成待办（`[ ]`），保持输出精简干练，拒绝臃肿长图文！

每次调用本 Skill 完成复盘后，执行以下**三重自动化闭环**：

1. **报告存盘**：保存为 `/Volumes/Macintosh HD_Data/obsidian/300_Resources/复盘总结/YYYYMMDD-GOBE复盘-[主题].md`。
   - Front Matter 规范：包含 `created: YYYY-MM-DD`、`updated: YYYY-MM-DD` 及 `tags: [GOBE, 复盘]`。
2. **任务同步**：自动提取复盘中的 🟡 **P1** / 🟢 **P2** 未完成行动待办，同步至 `/Volumes/Macintosh HD_Data/obsidian/200_Knowledge/to-do-list/AI-todo.md`，彻底移除已完成项。
3. **日志记录**：在 `/Volumes/Macintosh HD_Data/obsidian/999_Meta/log.md` 追加一行 `ADD` 记录。
